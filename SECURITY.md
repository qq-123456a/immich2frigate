# Security policy

Do not report vulnerabilities involving credentials, face images, identity mappings, or production systems in a public issue. If GitHub's private vulnerability reporting is enabled for this repository, use its **Report a vulnerability** link. Otherwise, contact the maintainer through the email address on the owner's GitHub profile; do not attach private data to a public issue.

The project must keep credentials out of persistent application state, logs, reports, and manifests. Treat Immich data and face-derived material as private runtime data and use synthetic fixtures in public contributions and CI.
